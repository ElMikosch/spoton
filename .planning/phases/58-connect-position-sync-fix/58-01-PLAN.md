<objective>
Perl half of the Connect position sync fix (Part B, 58-CONTEXT.md) — the hotfix that removes the regression introduced by the #126 fix.

The #126 fix added `notifyFromArray(['newmetadata'])` to the Connect change handler. That push happens immediately at track change, when `songElapsedSeconds` has just been reset to ~0 — so every LMS client renders a definitive position=0 while the binary's real position (mid-song Connect resume) has not arrived yet. Result: visible progress bar divergence.

Fix: remove the notify from the change handler and relocate it to `_fetchTrackMetadata`'s failure exit paths. The success path already notifies; with the two failure paths covered, every displayable exit of the metadata callback pushes the progress reset — preserving the #126 rapid-skip behavior (429 backoff → failure path → notification fires) without an eager position=0 push at change time.

Purpose: Ship the regression removal immediately, independent of the Rust rebuild (Plan 02).
Output: Modified `Plugins/SpotOn/Connect.pm`, all tests green.
</objective>
