<objective>
Fix CR-01 / Gap 1: Provide an admin-facing mechanism to configure the Pathfinder GraphQL hash,
plus close WR-02 (dead cache write) and WR-03 (sp_dc clear impossible). Per D-07, D-08.

Purpose: The Made For You feature ships non-functional because PATHFINDER_HOME_HASH_DEFAULT is
an unconfigurable placeholder with no write path. This plan adds a Settings field so an admin
can paste the live-captured hash from DevTools, wires Client.pm to read from prefs first
(persistent across restarts, unlike cache), adds a Status.pm indicator for hash status, fixes
the sp_dc clear UX gap (WR-03), and removes dead code (WR-02).

Output: Configurable Pathfinder hash via Settings, sp_dc clearable, dead code removed
</objective>
