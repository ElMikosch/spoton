<objective>
Create the backend state layer for the Auth Health Dashboard (D-01, D-02, D-03).

Three new pieces of state:
1. Audio-key cohort classification from daemon stderr (D-02 — passive indicator, no active probe)
2. Per-account last-API-call timestamp (D-01 PKCE indicator sub-field)
3. Unconditional periodic stderr scan hook in DaemonManager (feeds the audio-key classifier)

All reads are passive (cache-backed) so the dashboard (Plan 02) can display them without triggering any active probes or API calls.

Purpose: The dashboard (Plan 02) needs backend state that does not exist yet. Four of the five D-01 indicators already have query methods (needsReauth, accountNeedsMigration, WebPlayer::state, DaemonManager::helperInstances). This plan fills the two gaps: audio-key classification and last-API-call timestamp.

Output: Credentials.pm gains classifyAudioKeyError; DaemonManager._streamAlivePoll gains unconditional stderr scan; TokenManager.getToken gains last-API-call cache write; new t/22_audio_key_classifier.t unit test.
</objective>
