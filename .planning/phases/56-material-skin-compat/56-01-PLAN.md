<objective>
Fix Material Skin grid-view toggle for playlists (GH #124), add HomeExtras scrolled rows for MS home screen (GH #125), and add icons to all top-level and library menu entries (bonus).

Purpose: Material Skin disables grid/cover view when any item in a list lacks an icon. A single artwork-less playlist kills the toggle for the entire list. Top-level menus render as plain text without icons. MS home screen has no SpotOn scrolled rows.

Output: Modified Plugin.pm with fallback images and menu icons, new HomeExtras.pm module, 4 PNG image assets.
</objective>

    **New file: Plugins/SpotOn/HomeExtras.pm**

    Create with 3 packages in a single file, following Spotty's multi-package pattern exactly:

    Package 1 — Plugins::SpotOn::HomeExtras: top-level initializer that calls initPlugin on each concrete extra class. Two extras: Plugins::SpotOn::HomeExtraRecentlyPlayed and Plugins::SpotOn::HomeExtraTopTracks. Skip Made For You (the CONTEXT says it returns a textarea hint when sp_dc is missing, which renders as junk in a scrolled row).

    Package 2 — Plugins::SpotOn::HomeExtraBase: inherits from Plugins::MaterialSkin::HomeExtraBase. Its initPlugin accepts named args (feed, tag, title, subtitle) and calls SUPER::initPlugin with: feed => the provided feed coderef, tag => "SpotOnExtras$tag", extra => { title, subtitle (optional), icon => Plugins::SpotOn::Plugin->_pluginDataFor('icon'), needsPlayer => 1 }. The needsPlayer flag is required because _getAccountId resolves the per-player active account.

    Package 3 — Plugins::SpotOn::HomeExtraRecentlyPlayed: inherits from SpotOn::HomeExtraBase. Calls SUPER::initPlugin with title => 'PLUGIN_SPOTON_RECENTLY_PLAYED', subtitle => 'PLUGIN_SPOTON', feed => \&Plugins::SpotOn::Plugin::_recentlyPlayedFeed, tag => 'RecentlyPlayed'.

    Package 4 — Plugins::SpotOn::HomeExtraTopTracks: inherits from SpotOn::HomeExtraBase. Calls SUPER::initPlugin with title => 'PLUGIN_SPOTON_TOP_TRACKS', subtitle => 'PLUGIN_SPOTON', feed => \&Plugins::SpotOn::Plugin::_topTracksFeed, tag => 'TopTracks'.

    Each package ends with `1;`. The file uses strict.

    **Plugin.pm — add postinitPlugin sub:**

    Add a postinitPlugin sub after shutdownPlugin (around line 280). The sub takes $class as shift. It checks for Material Skin with the exact two-condition guard from Spotty: `Slim::Utils::PluginManager->isEnabled('Plugins::MaterialSkin::Plugin') && Plugins::MaterialSkin::Plugin->can('registerHomeExtra')`. Inside the guard, eval-require Plugins::SpotOn::HomeExtras. Log error on failure via $log->error. This is the same pattern as Spotty's postinitPlugin lines 209-215.

    The sub must be named exactly postinitPlugin (LMS calls it by convention after all plugins have called initPlugin).
