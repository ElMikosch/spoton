<objective>
Strip the dual-flavor system (own/bundled) from Client.pm per D-04. Remove
_resolveStartFlavor, _lookupBundledHint, _rememberBundledHint, _is404Deprecated,
@KNOWN_DEPRECATED_FAMILIES, and the bundled-fallback retry branch from
_doFlavouredRequest's error callback. Simplify the getToken call site from 3-arg
(accountId, flavor, cb) to 2-arg (accountId, cb). Collapse per-flavor rate-limit
cache keys to a single key. Update t/08_api_client.t to match.

Purpose: D-04 completion — the flavor system was a Keymaster-specific workaround that
PKCE tokens do not need (Spike 002: 21/21 endpoints work with single client_id).

Output: Simplified Client.pm, updated test suite.
</objective>
