<objective>
Rewrite TokenManager.pm from Keymaster-based binary spawning to PKCE-native pure Perl token
management. All token lifecycle operations (fetch, refresh, cache, error handling) use PKCE.pm
primitives -- no librespot subprocess. The flavor system (own/bundled) is removed from
getToken/_cacheToken/removeAccount. Re-auth state tracking (needsReauth flag) is added for
the 4-channel notification system (D-08). Covers D-01, D-03, D-04, D-05, D-06, D-07, D-08
(Channels 3+4), D-09.

Extends PKCE.pm error callback to surface HTTP status code and OAuth error type,
enabling TokenManager to distinguish permanent revocation (invalid_grant/400) from transient
network failures (Pitfall 1 from RESEARCH.md).

Incorporates Fable 5 review findings: M-1 (cache TTL 'never'), M-4 (getToken short-circuit
on needsReauth), M-5 (refreshAllTokens calls _refreshToken directly + displayName repair
preserved), M-6 (400 without parseable oauth_error triggers reauth), L-1 (_fetchDisplayName
3-arg signature), L-4 (SPOTIFY_ME_URL constant name), L-6 (public clearNeedsReauth).

Purpose: AUTH-05 -- TokenManager.pm refreshes Web API tokens via standard OAuth refresh flow,
no binary spawn needed for API calls.

Output: Rewritten TokenManager.pm, extended PKCE.pm error path, rewritten test suite.
</objective>
